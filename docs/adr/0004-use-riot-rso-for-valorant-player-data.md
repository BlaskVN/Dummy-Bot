# Use Riot RSO for VALORANT player data

Automated VALORANT player data will only come from Riot's approved APIs after the player opts in through Riot Sign On. A Discord user may save one global Tracker Profile Link, cannot configure a different link per Guild, and allows members of a shared Guild to view it for navigation. The bot will never scrape tracker.gg or treat that link as verified identity, trading an easier unofficial integration for policy compliance and long-term stability.
