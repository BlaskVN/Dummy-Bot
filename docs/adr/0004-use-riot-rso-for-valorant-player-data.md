# Use Riot RSO for VALORANT player data

Automated VALORANT player data will only come from Riot's approved APIs after the player opts in through Riot Sign On (Linked Riot Account). Profile display in any Guild requires explicit Guild Profile Visibility consent. The bot strictly forbids scraping tracker.gg or saving unverified third-party profile links, trading an easier unofficial integration for Riot Games and Tracker Network policy compliance and long-term stability.
